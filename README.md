# AI Speech Recognition System

## Overview

The AI Speech Recognition System is a Python-based application that converts spoken audio into text using Speech Recognition technology. The application captures voice input through a microphone and transcribes it into readable text using Google's Speech Recognition API.

A professional graphical user interface (GUI) was developed using Tkinter for easy interaction and accessibility.

This project was developed as part of an Artificial Intelligence Internship Task.






## Features

- Real-time speech-to-text conversion
- Microphone-based voice input
- Interactive GUI interface
- Fast and accurate speech recognition
- Background noise reduction
- Clear text functionality
- Error handling support
- Lightweight and beginner-friendly project


## Technologies Used

- Python
- SpeechRecognition
- PyAudio
- Tkinter
- Google Speech Recognition API
